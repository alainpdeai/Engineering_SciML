## 卡一 · 边界行清零未恢复主对角 → 奇异矩阵，NaN 静默通过（F4）

### 现象

运行 `python diagnostics/buggy_solver.py`：进程**退出码 0**，stdout 打印「求解成功: [nan nan nan nan nan]」，
只有 stderr 出现 `MatrixRankWarning: Matrix is exactly singular`。只看退出码或前几行会误判成功。

### 数字证据

| 项 | 实测 | 判据 |
| :--- | :--- | :--- |
| 边界行内容 | 全 0（含主对角元） | 对角须恢复为 1 |
| spsolve 告警 | `Matrix is exactly singular` | 无告警、残差≈0 |
| 解向量 | `[nan nan nan nan nan]` | 有限值 |
| 进程退出码 | 0（**陷阱**） | 不可单独作为通过依据 |

### 根因

`A[0, :] = 0.0` 后未执行 `A[0, 0] = 1.0` → 该行全零 → $\det(A)=0$。
按 `assemble_poisson_system` 的「清行 + 清列 + 置 1」修复后，同题整体残差 $2.1\times10^{-15}$（**max 范数**；2 范数 $1.13\times10^{-14}$，见 CSV `residual` 列，N=41）。

### 误诊排除

- **A 求解器太弱？** 否——结构性奇异，任何直接/迭代法都失败。
- **B 方程不适定？** 否——正确装配后 MMS 收敛阶 2.001 → 2.000（CSV，真 $L^2$ 口径）。
- **D 网格/参数错？** 否——与 $h$ 无关，任意 $N$ 同样奇异。

## 卡二 · 只划行不清列 → $A\neq A^T$，CG 的对称正定前提被破坏（F4）

### 现象

正文故障二：只划边界行、不清对应列，导致矩阵非对称；直接法解仍与正确版相差仅 $6.2\times10^{-15}$。这会破坏 CG 所需的对称正定理论前提与收敛保证，但具体迭代残差表现依赖右端和迭代器，不能概括为必然震荡或必然不收敛。

### 数字证据（$N=41$，同款五点装配复算）

| 装配 | nnz | $\max\|A-A^T\|$ | 直接法解 vs 正确版 |
| :--- | :--- | :--- | :--- |
| 正确（行+列同步清，`assemble_poisson_system`） | 7609 | **0.0** | 基准 |
| 只划行（列不清） | 7765 | **1.0** | 差 $6.2\times10^{-15}$ |

列不清多出 156 个悬置系数（$=160-4$ 个非角边界节点，各留 1 个），$A-A^T$ 出现 $\pm1$。
**直接法解仍「看起来对」**（差 $6.2\times10^{-15}$）——这正是它能潜伏的原因；而 CG 的 SPD 前提已经不成立。

### 根因与对账

对账正文诊断题**标准答案 C**：边界行赋值后必须把该未知数从其他方程系数中消去（或对称化处理），
否则矩阵非对称，CG 的短递推与 SPD 收敛保证不再适用。具体运行可能偶然收敛，也可能停滞或震荡，须给定右端、初值、预条件器、容差与残差序列后才能描述；无论残差如何，首要问题都是装配层错误，而非迭代次数不足。

### 误诊排除

- **A 加大 maxiter？** 不改变被破坏的前提（$A\neq A^T$ 是静态事实）。
- **B 换 GMRES？** 能解出来，但用更贵的方法掩盖装配 bug，还丢掉对称性这条可审计证据。
- **D 网格太粗/条件数大？** 条件数只影响收敛速度；正确版 $N=41$ 残差实测 $2.1\times10^{-15}$。

## 卡三 · 一阶单边 Neumann → 整体收敛阶从 2 降为 1（F4）

### 现象

验证三件套只对「五点内点格式」承诺接近 2；换一阶单边 Neumann 必须**另列一行说明理论阶数改变**（正文⑥注），
而不是把结果硬拟合成二阶。

### 数字证据（一维最小例 $-u''=f$，$u(0)$ Dirichlet、$u'(1)$ 单边差分，$u^*=e^x$，$u''(1)=e\neq0$）

| 网格对 | 一阶 $(u_{N-1}-u_{N-2})/h$ | 二阶 $(3u_{N-1}-4u_{N-2}+u_{N-3})/2h$ |
| :--- | :--- | :--- |
| 21→41 | $p=1.017$ | $p=2.001$ |
| 41→81 | $p=1.009$ | $p=2.001$ |
| 81→161 | $p=1.004$ | $p=2.000$ |

一阶 $L^2$：$4.02\times10^{-2}\to1.99\times10^{-2}\to9.87\times10^{-3}\to4.92\times10^{-3}$（每格加密恰减半）；二阶 $1.46\times10^{-3}\to3.64\times10^{-4}\to9.10\times10^{-5}\to2.27\times10^{-5}$。

### 根因

单边一阶截断缺陷 $-h\,u''(1)/2$ 落在 $O(1)$ 系数的边界行上，经离散 Green 函数放大为 $O(h)$ 全局误差；
二阶单边缺陷 $O(h^3)$（行按 $2h$ 缩放后）→ 全局 $O(h^2)$。

### 误诊排除

- **D「硬拟合成二阶」**：禁止——输出以本机运行结果为准，不得把预期阶数写成固定承诺（正文⑤注）。
- **选例退化会掩盖掉阶**：若制造解恰有 $u''(1)=0$（如 $\sin\pi x$），一阶单边缺陷降为 $O(h^3)$，
  实测仍 $p=2.047/2.024/2.012$——**看到二阶不代表一阶单边没问题**；暴露它必须选 $u''(\text{边界})\neq0$ 的制造解。

## 误诊清单与现场排查

1. 先对形状与 nnz：与五点模板不符 → 装配循环写错（卡外，F4）。
2. $\max|A-A^T|\neq0$ → 只划行不清列（卡二），CG 不可用，先修装配再谈求解器。
3. 退出码 0 但解含 NaN / `Matrix is exactly singular` → 边界行对角未恢复（卡一）。
4. 斜率 $\approx1$ 而预期 2 → 查 Neumann 阶数（卡三），并确认制造解 $u''(\text{边界})\neq0$。
5. **五项全过再考虑更换求解器**（warn-box 原则：先体检，后换件）。

## 误差口径节（真 $L^2$ vs 节点 RMS，2026-10-16 统一并双向留痕）

本单元唯一误差口径为**真 $L^2$ 范数**：二维 $\sqrt{h^2\sum e^2}$（覆盖含边界的全部 $N^2$ 个节点；齐次 Dirichlet 下边界节点误差恒为 0，不影响阶数），一维 $\sqrt{h\sum e^2}$。源稿⑤现场运行代码、`run_benchmarks`（CSV `l2_error` 列）、门禁测试 `tests/test_mms.py` 与本卡附录同口径。

| 口径 | 二维阶（N=21/41/81/161） | 一阶单边（卡三） | 二阶单边（卡三） |
| :--- | :--- | :--- | :--- |
| 真 $L^2$（现行唯一口径） | 2.001 / 2.000 / 2.000 | 1.017 / 1.009 / 1.004 | 2.001 / 2.001 / 2.000 |
| 节点 RMS $\sqrt{\mathrm{mean}(e^2)}$（旧口径，入档备查） | 1.967 / 1.983 / 1.991 | 0.999 / 1.000 / 1.000 | 1.984 / 1.992 / 1.996 |

含端点的 $N\times N$ 网格（间距 $h=1/(N-1)$）上，$\mathrm{RMS}=\sqrt{\sum e^2/N^2}$、真 $L^2=h\sqrt{\sum e^2}$，所以 $\mathrm{RMS}/\|e\|_{L^2,h}=(N-1)/N$，即真 $L^2/\mathrm{RMS}=N/(N-1)=1+1/(N-1)$。这个随网格变化的因子使 RMS 斜率比真 $L^2$ 低约 0.03；两种口径**结论同为二阶**，此处两行都保留，不允许只报有利的一行。一维退化例（$u^*=\sin\pi x$，$u''(1)=0$）在真 $L^2$ 下实测 $p=2.047/2.024/2.012$（RMS 下 2.030/2.015/2.008），同样掩盖一阶单边的掉阶——口径选择救不了选例退化。

## 附录 · 卡三最小复现（与卡内数字同源，真 $L^2$ 口径）

```python
import numpy as np
def sweep(first_order, N):   # u*=e^x, f=-e^x, g=e, u(0)=1
    h = 1/(N-1); x = np.linspace(0, 1, N); ue = np.exp(x); f = -np.exp(x)
    M = np.zeros((N, N)); r = np.zeros(N); M[0, 0] = 1; r[0] = 1
    for i in range(1, N-1):
        M[i, i-1] = -1; M[i, i] = 2; M[i, i+1] = -1; r[i] = h*h*f[i]
    if first_order:
        M[-1, -1] = 1; M[-1, -2] = -1; r[-1] = h*np.e
    else:
        M[-1, -1] = 3; M[-1, -2] = -4; M[-1, -3] = 1; r[-1] = 2*h*np.e
    return np.sqrt(h*np.sum((np.linalg.solve(M, r) - ue)**2))
# p = log(e_i/e_{i+1}) / log(h_i/h_{i+1})，N = 21,41,81,161；真 L^2 = sqrt(h*sum(e^2))
```

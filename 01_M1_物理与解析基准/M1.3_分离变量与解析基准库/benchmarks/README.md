# M1.3 解析基准库 (G1 Milestone Benchmarks)

本目录为《数理方程与 AI 求解》课程体系 W3 里程碑 **G1 解析基准库验收** 的核心资产沉淀，包含抛物型与双曲型方程的标准分离变量解析基准解。

---

## 包含基准列表

| 文件 | 方程类型 | 物理场景 | 核心检验指标 |
| :--- | :--- | :--- | :--- |
| `heat_1d_square_wave.py` | 抛物型 ($u_t=\alpha u_{xx}$) | 方波初温热扩散平滑 | $t=0.01$ 时 $N=3,6,11$ 的 $L^\infty$ 误差 ($1.2\times10^{-2}\to7.2\times10^{-10}$) 及能量单调衰减 |
| `wave_string_modes.py` | 双曲型 ($u_{tt}=c^2u_{xx}$) | 固定端弦三角拨弦驻波 | 机械能跨时刻封闭守恒 ($E \approx 2.3522$，浮动 $< 3\times10^{-5}$) |
| `metadata.json` | 规范元数据 | 全局基准索引与容差 | 包含方程形式、级数公式、边界条件及验收阈值 |

## 快速复现命令

### 1. 运行热传导方波基准
```bash
python benchmarks/heat_1d_square_wave.py
```

### 2. 运行弦振动驻波守恒基准
```bash
python benchmarks/wave_string_modes.py
```

### 3. 运行自动化 pytest 验收套件
```bash
pytest tests/test_benchmarks.py -v
```

## G1 关卡验收判定原则

1. **精确解析解对照**：必须给出解析级数封闭公式与对称性判定证据（严防奇偶展开套错导致的 F4 错误）；
2. **物理守恒/耗散证据**：抛物型方程必须证明能量谱严格单调衰减；双曲型方程必须证明总机械能严格守恒；
3. **区分 Gibbs 截断与离散发散**：在间断点跳跃区域设置安全隔离区评估 $L^\infty$ 误差。

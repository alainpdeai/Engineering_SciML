## 卡 1 · F2：CFL 超过 1 后 leapfrog 指数爆炸

**现象**

```text
CFL = 0.90：max|u| = 1.000e+00，E_max / E_0 = 1.000e+00
CFL = 1.00：max|u| = 1.000e+00，E_max / E_0 = 1.000e+00
CFL = 1.05：max|u| = 1.803e+201，能量已溢出为 inf/nan
```

**有 bug 的代码**

```python
nu = 1.05                       # 超过 CFL 上限
t, U, dt = leapfrog_wave(x, t_end, c, cfl=nu, f=f)
```

**根因**

leapfrog 的放大因子在 $|\nu| > 1$ 时绝对值大于 1，最高频模态每步被放大；约 $10^{-16}$ 的舍入误差就是种子。这不是"边界没设好"，也不是"网格太粗"，而是时间步越过了稳定边界。

**修复**

取 $\nu = c\Delta t/\Delta x \le 1$（本单元取 0.9 留余量），或改用隐式格式。**不要**用滤波、裁剪或加阻尼掩盖爆炸。

**验证证据**

`tests/test_characteristics.py::test_cfl_above_one_is_unstable` 与 `::test_cfl_at_one_is_marginally_stable`。

## 卡 2 · F2 预告：数值依赖域比物理锥更宽，远端"先知先觉"

**现象**

```text
初值支集 = [-1.20, -0.80]，远端探测点 x = 3.00
物理到达时间 t_phys = 3.8000
t = 2.00 / 3.00 / 3.70  解析解 |u(x_far)| = 0.000e+00   （波还没到，解严格为零）
CFL = 0.5：t_num = 3.7100（t_num / t_phys = 0.976）
CFL = 0.9：t_num = 3.7480（t_num / t_phys = 0.986）
```

**根因**

leapfrog 在 $n$ 步后，$u_j^n$ 依赖 $[x_j - n\Delta x,\ x_j + n\Delta x]$ 内的初值，即数值依赖域为 $[x_0 - ct/\nu,\ x_0 + ct/\nu]$。当 $\nu < 1$ 时它**比物理特征锥更宽**，因此数值解原则上能从更远的初值取得影响，首次响应早于 $t_{phys}$。

注意区分两件事：数值锥更宽（可提前响应）与数值相速度偏慢（色散使波包走得略慢）同时存在；前导尾部幅值指数小，所以用 $10^{-6}$ 阈值测得的提前量远小于锥宽比 $1/\nu$。

**修复/正确用法**

1. 先用特征线确定物理依赖域 $[x_0 - ct, x_0 + ct]$，再检查离散模板是否落在入流方向；
2. 报告数值响应时间与 $t_{phys}$ 的比值，而不是只说"看起来对"；
3. 不要把"数值提前响应"当作物理结果写进报告。

**验证证据**

`tests/test_characteristics.py::test_causality_before_wavefront_arrival` 与 `::test_numerical_cone_is_not_narrower_than_physical_cone`。

## 卡 3 · F4：把目标点 $x_0 = 0$ 的特征脚点硬套到偏移脉冲上

**现象**

画 d'Alembert 双行波时，把两条特征脚线画在 $x = \pm ct$，而脉冲中心其实在 $x_0 = -0.35$。学生运行后看到波峰与虚线完全对不上。

**有 bug 的代码**

```python
ax.axvline(-c*t, ls="--", label="左特征脚点")   # 只对目标点 x0 = 0 成立
ax.axvline( c*t, ls="--", label="右特征脚点")
```

**根因**

依赖域是**相对目标点**定义的：目标点 $(x_0, t)$ 的脚点是 $x_0 \pm ct$，不是 $0 \pm ct$。忘记减去 $x_0$ 是把"公式记忆"当成了"物理量"，属于 F4（结果不合理，但程序不报错）。

**修复**

```python
left_foot, right_foot = characteristic_feet(x0, t, c)   # 返回 (x0 - ct, x0 + ct)
```

**验证证据**

`benchmarks/characteristics_wave.py::characteristic_feet` 与 `tests/test_characteristics.py::test_characteristic_feet_positions`。

## 卡 4a · F4：离散能量漏用梯形权重，自由端假漂移 1.65%

**现象**（公共配置下实跑）

```text
                       正确（梯形权重）      本卡 bug（单位权重）
  fixed 边界相对漂移     3.94e-15            3.94e-15     ← 纹丝不动
  free  边界相对漂移     1.12e-14            1.65e-02     ← 凭空涨 1.65%
```

**关键判别特征**：这个 bug **只伤自由端**，固定端完全不受影响。因为固定端上 $u\equiv 0$，端点动能项本来就是 0，权重取 1 还是 $1/2$ 没有区别；只有自由端 $u_x=0$ 而 $u\ne 0$ 时，端点半权才起作用。**看到"固定端干净、自由端脏"就该想到权重，而不是想到边界模板。**

**有 bug 的代码**（`benchmarks/characteristics_wave.py::discrete_energy` 内的权重构造）

```python
def discrete_energy_buggy(u_prev, u_next, c, dt, dx):
    kinetic  = ((u_next - u_prev) / dt) ** 2
    weights  = np.ones_like(kinetic)        # BUG: 忘了端点取半权
    # weights[0] = 0.5 ; weights[-1] = 0.5   ← 正确实现必须补上这两行
    grad_next  = np.diff(u_next) / dx
    grad_prev  = np.diff(u_prev) / dx
    return 0.5 * dx * (np.sum(weights * kinetic) + np.sum(c ** 2 * grad_next * grad_prev))
```

**复现**（接公共配置）

```python
x  = np.linspace(0.0, 1.0, 401); dx = x[1] - x[0]
f  = lambda z: np.where(np.abs((z-0.5)/0.15) < 1.0, (1.0-((z-0.5)/0.15)**2)**2, 0.0)
for boundary in ("fixed", "free"):
    t, U, dt = leapfrog_wave(x, 4.0, 1.0, cfl=0.9, f=f, boundary=boundary)
    E = np.array([discrete_energy_buggy(U[i], U[i+1], 1.0, dt, dx) for i in range(len(U)-1)])
    print(boundary, np.max(np.abs(E - E[0])) / abs(E[0]))
# fixed 3.937586253536109e-15
# free  1.6501e-02
```

**根因**

$u_x=0$ 只约束**梯度**，不约束端点的 $u$。端点动能 $\tfrac{1}{2}w_j\bigl(\Delta u/\Delta t\bigr)^2$ 仍是非零量，必须按梯形规则取半权 $w=1/2$；漏掉就等于**把端点动能计了两次**，于是出现与物理无关的 $O(10^{-2})$ 假漂移。固定端 $u\equiv0$ 使该项恒为零，所以看不出来。

**修复**

`weights[0] = weights[-1] = 0.5`（即 `benchmarks/characteristics_wave.py::discrete_energy` 的默认分支）。

**验证证据**

`tests/test_characteristics.py::test_discrete_energy_is_conserved[fixed]` 与 `[free]`；数值见 `results.json` 的 `energy_relative_drift_fixed` / `_free`。

## 卡 4b · F4：自由端事后贴值替代鬼点，能量整体崩塌

**现象**（公共配置下实跑）

```text
                       正确（鬼点模板）      本卡 bug（事后贴值）
  仅右端贴值            1.12e-14             9.9999e-01
  两端都贴值            1.12e-14             1.0000e+00
  两端贴值用在 fixed 上  3.94e-15             1.0000e+00   ← 固定端也坏
```

**关键判别特征**：这个 bug **两端都坏、且坏到能量归零或翻倍**，与卡 4a 的"只伤自由端、量级 $10^{-2}$"截然不同。两者量级差两个数量级，可以直接据此区分是哪个 bug。

**有 bug 的代码**（完整实现，替代 `_next_step` 的 free 分支）

```python
def leapfrog_paste_bug(x, t_end, c, cfl, f):
    """BUG：把 u_x = 0 事后贴到解上，而不是写进差分模板。"""
    dx = float(x[1] - x[0]); dt = cfl * dx / c
    nt = max(1, int(round(t_end / dt))); dt = t_end / nt
    nu2 = (c * dt / dx) ** 2
    u0 = np.asarray(f(x), dtype=float).copy()
    u1 = _first_step(u0, np.zeros_like(u0), dt, nu2, "free")   # 首步仍用鬼点
    U = [u0, u1]
    for _ in range(nt - 1):
        prev, cur = U[-2], U[-1]
        nxt = np.empty_like(cur)
        nxt[1:-1] = (2.0 * cur[1:-1] - prev[1:-1]
                     + nu2 * (cur[2:] - 2.0 * cur[1:-1] + cur[:-2]))
        nxt[0]  = cur[1]        # BUG：贴左端
        nxt[-1] = cur[-2]       # BUG：贴右端
        U.append(nxt)
    return U, dt
```

**复现**

```python
x = np.linspace(0.0, 1.0, 401); dx = x[1] - x[0]
f = lambda z: np.where(np.abs((z-0.5)/0.15) < 1.0, (1.0-((z-0.5)/0.15)**2)**2, 0.0)
U, dt = leapfrog_paste_bug(x, 4.0, 1.0, 0.9, f)
E = np.array([discrete_energy(U[i], U[i+1], 1.0, dt, dx) for i in range(len(U)-1)])
print(np.max(np.abs(E - E[0])) / abs(E[0]))    # 1.0000e+00
```

**根因**

`u[0] = u[1]` 约束的是**端点值 $u_0$**，而 $u_x=0$ 要求的是**虚拟点 $u_{-1}=u_1$**。两者不是一回事：

- 鬼点条件 $u_{-1}=u_1$ 参与内部点 $j=1$ 的更新，作用在**格式内部**；
- 贴值条件 $u_0=u_1$ 作用在**存储单元**上，把端点强行钉死，端点自由度被抹掉。

于是内部格式仍在按 $u_x=0$ 演化，而端点却被外部覆盖，两者的能量账本不再配平，能量在几步内整体塌掉。**这正是"把边界条件事后贴到解上"的典型反模式。**

> 旧版失效卡只给了两行 `u[0] = u[1]; u[-1] = u[-2]`，没有说明它替换的是哪一步的哪一段。这里不同放置（首步/每步、仅右端/两端）会给出 $8.2\times10^{-3}$ 到 $1.0$ 的巨大差异，**该片段本身不足以决定现象数字**——所以本卡给出完整实现。

**修复**

把 $u_x=0$ 写进差分模板，用镜像鬼点 $u_{-1}=u_1$、$u_N=u_{N-2}$，端点更新为

$$u_0^{n+1} = 2u_0^n - u_0^{n-1} + 2\nu^2\,(u_1^n - u_0^n).$$

**验证证据**

`benchmarks/characteristics_wave.py::_next_step` 的 `boundary == "free"` 分支；`tests/test_characteristics.py::test_discrete_energy_is_conserved[free]`。

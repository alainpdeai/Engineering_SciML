# M1.5 失效卡 · F4：简并子空间的旋转与归一化口径

> 立场：**本征求解的失败不能只看「有无特征值」。**
> 数字来源：`tests/test_membrane_spectrum.py --dump`（本机实测，numpy 2.4.6 / scipy 1.17.1）。
> 离散：Q1 双线性矩形单元、2×2 高斯积分、一致质量矩阵；Dirichlet 用消元。

---

## 故障一 · 振型「对不上」该不该返工

### 现场

正方形膜模态评审：数值第二、三阶「模态云图」与教科书解析振型逐点不同，
评审据此判定模型有错、要求返工；但特征值与前两阶子空间投影全部正确。

### 复现：在简并子空间里转一圈（$a=b=1$，$n=24$）

$\lambda_2=\lambda_3=49.58811833$，相对间距 **2.72e-14**（解析 $5\pi^2=49.348022$，
有限元从**上方**逼近，偏高 0.49%）。

| 旋转角 | 最大本征残差 $\lVert Kq-\lambda Mq\rVert/\lVert Kq\rVert$ | 逐点 $\lvert\cos\rvert$ |
| :--- | :--- | :--- |
| 0.0° | 1.010e-13 | **0.7072** |
| 15.0° | 1.033e-13 | 0.8661 |
| 30.0° | 1.047e-13 | 0.9660 |
| 45.0° | 1.055e-13 | **1.0000** |
| 60.0° | 1.049e-13 | 0.9659 |
| 75.0° | 1.027e-13 | 0.8660 |
| 90.0° | 1.004e-13 | **0.7072** |

**本征残差全程 1e-13 不变，逐点匹配度却在 0.707 … 1.000 之间摆动。**
逐点比较衡量的是**求解器碰巧返回了哪一组基**，不是模型对不对。

真判据 —— **子空间投影残差** $\lVert VV^{\!T}MQ-Q\rVert/\lVert Q\rVert$ = **1.871e-14**，与旋转无关。

> ⚠ 注意：固定旋转 45° 是不可靠的写法。求解器返回的基本身是任意的，
> 45° 有可能恰好把它转回解析方向（实测 45.0° 时 $\lvert\cos\rvert=1.0000$）。
> 必须**扫遍旋转角**才能看到「结论随基摆动」这件事。

### 误区排查

| 误区 | 实测反驳 |
| :--- | :--- |
| A 收紧 Lanczos 容差 | 会得到同一子空间的另一组基；$\lvert\cos\rvert$ 照样摆动 |
| B 网格太粗 | 加密不消除简并：$n=16/24/32$ 时间距为 1.4e-15 / 2.7e-14 / 1.8e-14 |
| D 材料参数差量级 | 特征值会跟着错；这里**特征值全对、振型不同**，正是简并的指纹 |

### POE：拉长矩形解除简并（非失效）

| $b/a$ | $\lvert\lambda_3-\lambda_2\rvert/\lambda_2$ |
| :--- | :--- |
| 1.00 | 2.72e-14 |
| 1.02 | **2.41e-02** |
| 1.20 | **2.43e-01** |

对称性破缺，属正常物理 —— **误判为装配错才是 F4**。

## 故障二 · 振型看着差不多，$M$-正交性却通不过

### 现场

前四阶模态云图与解析振型逐点都很接近，特征值误差也在 1e-6 以内，
但 $Q^{\!T}MQ$ 明显偏离单位阵，模态能量分解与总能量对不上。

### 根因：$Q^{\!T}MQ\approx I$ 只在 **$M$-归一化**下成立

$n=24$，跨整个谱抽样（阶次 $[0,1,2,132,264,528]$）：

| 口径 | $Q^{\!T}MQ$ |
| :--- | :--- |
| $M$-归一化（$q_i^{\!T}Mq_i=1$） | 与 $I$ 的最大偏差 **8.88e-16** |
| 欧氏归一化（$\lVert q\rVert_2=1$） | **非对角** 2.80e-19（仍然正交！） |
| 欧氏归一化 | **对角** $=[1.73,1.71,1.71,1.05,0.70,0.20]\times10^{-3}$，极差比 **8.798** |

**坏的是对角，不是非对角** —— 欧氏归一化仍然保持正交，只是每个向量的「质量长度」不再等于 1。

> ⚠ 一个会漏掉它的陷阱：$\mathrm{diag}(Q^{\!T}MQ)$ 恰好等于各阶的**质量矩阵 Rayleigh 商**
> $v^{\!T}Mv/v^{\!T}v$。对**低阶**模态它几乎各向同性 —— 只抽查前六阶时极差比只有 **1.023**，
> 看起来完全正常。口径失配要到**跨整个谱**抽样才暴露（8.798）。

### 为什么它藏得住

- 特征值：一字不变。
- 振型**方向**：一字不变（最小 $\lvert\cos\rvert = 0.999999999999$）。只有长度变了。

### 后果：模态能量分解

$u$ 取在前 8 阶张成的子空间内，$u^{\!T}Mu = 3.46947612$：

| 口径 | $\sum c_i^2$ | 相对偏差 |
| :--- | :--- | :--- |
| $M$-归一化（$c_i=q_i^{\!T}Mu$） | 3.46947612 | **0.000e+00** |
| 欧氏归一化（$c_i=q_i^{\!T}u$） | 2.0657e+03 | **5.944e+02**（594 倍） |

## POE：固定 → 自由边界

| 边界 | $\lambda_1\ldots\lambda_4$（$n=24$） |
| :--- | :--- |
| 固定（Dirichlet） | 19.76741 / 49.58812 / 49.58812 / 79.40883 |
| 自由（Neumann） | **−8.45e-13** / 9.88371 / 9.88371 / 19.76741 |

- 解析基频：Dirichlet $2\pi^2=19.73921$（实测偏高 0.14%）；自由首个非零 $\pi^2=9.86960$。
- 自由边界出现 **$\lambda\approx0$ 的刚体平移模** —— 报基频时若把它当成第一阶，会得到 0 Hz。
- 低阶频率**下降**（9.884 < 19.767）符合「约束减弱 ⇒ 刚度下降」。
  **若改完边界频率反升，说明边界装配反了（F4）。**

## 检查清单（顺序不可颠倒）

1. **先说清楚用的是哪种归一化口径**，再谈 $Q^{\!T}MQ\approx I$。
2. **简并时改比子空间投影**，不要逐点比振型；也不要比符号。
3. 正交性检查要**跨整个谱**抽样，只查低阶会漏掉质量矩阵口径失配。
4. **本征残差只说明方程被解了**，不说明矩阵装对了（装配错误见 M2.6 的秩判据）。
5. 报谱误差时同时报**收敛阶**（实测 $8\!\times\!10\to32\!\times\!40$：1.100e-02 → 2.742e-03 → 6.849e-04，比值 4.01 / 4.00，二阶）。
6. 自由/自然边界先确认**有没有零频刚体模**，再报基频。

> 课程立场：AI 可以帮你装配矩阵、求谱、画云图，
> 但不能替你判断「特征值全对、振型不同」到底是模型错了还是简并子空间转了个角度。

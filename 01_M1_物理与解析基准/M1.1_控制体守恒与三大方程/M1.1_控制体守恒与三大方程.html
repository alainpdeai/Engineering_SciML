失效驱动 · F4 结果不合理

先看一个“看起来合理”的错误模型

现场故障 · F4：温度场没有报错，曲线也很平滑，但总能量却在没有热源时增加。问题可能不是求解器，而是通量方向或单位写反了。
先不要运行：如果一维控制体左侧流入热流、右侧流出热流，且没有源项，储存变化率应该是什么符号？把判断写下，再运行下一格。
python · 先看一个“看起来合理”的错误模型 可编辑 · Shift+Enter 运行
import numpy as np
import matplotlib.pyplot as plt
x = np.linspace(0, 1, 101)
k = 2.0
T = 100.0*x*(1.0-x)
q = -k*np.gradient(T, x)
storage_correct = -np.gradient(q, x)
storage_wrong = np.gradient(q, x)
print("正确符号平均储存变化率:", round(float(storage_correct.mean()), 3))
print("写反符号平均储存变化率:", round(float(storage_wrong.mean()), 3))
plt.figure(figsize=(6.2,3.2))
plt.plot(x, storage_correct, label="correct: -dq/dx")
plt.plot(x, storage_wrong, "--", label="wrong: +dq/dx")
plt.axhline(0, color="gray", lw=1)
plt.xlabel("x"); plt.ylabel("storage rate")
plt.title("F4 diagnostic: flux sign changes the physics")
plt.legend(); plt.show()

Step 1 · 物理量翻译成控制体账本

任何守恒律，都可以先写成四项账本

ddt∫Vρϕ dV=−∮SJ⋅n dS+∫Vs dV\frac{d}{dt}\int_V \rho\phi\,dV=-\oint_S\mathbf J\cdot\mathbf n\,dS+\int_V s\,dVdtd​∫V​ρϕdV=−∮S​J⋅ndS+∫V​sdV

左侧：控制体内的储存

ρφ 是单位体积携带的守恒量：热量用 ρcₚT，质量用 ρ，动量用 ρu。

右侧：边界交换与内部生成

J·n 是穿过边界的外法向通量；s 是内部源项。负号表示“流出会减少库存”。

> 储存变化 → − 边界净流出 → 内部生成 → 局部 PDE

> 关键习惯：先写控制体积分式，再用散度定理变成局部微分式。

(拆解公式) 带看四项积分账本，拆解储热、外法向通量负号与内部源项，说明散度定理将总账化为局部微分账本。

Step 2 · 能量守恒 + Fourier 定律

热传导方程：能量账本的局部版本

ddt∫VρcpT dV=−∮Sq⋅n dS+∫VQ dV\frac{d}{dt}\int_V \rho c_p T\,dV=-\oint_S\mathbf q\cdot\mathbf n\,dS+\int_V Q\,dVdtd​∫V​ρcp​TdV=−∮S​q⋅ndS+∫V​QdV

q=−k∇T⟹ρcp∂T∂t=∇⋅(k∇T)+Q\mathbf q=-k\nabla T\quad\Longrightarrow\quad \rho c_p\frac{\partial T}{\partial t}=\nabla\cdot(k\nabla T)+Qq=−k∇T⟹ρcp​∂t∂T​=∇⋅(k∇T)+Q

物理量

T 温度，k 热导率，ρcₚ 体积热容，Q 体热源。

不可逆性

无源时高频温差衰减，热场平滑化；这预告 M1.3 模态衰减与 M2.2 稳定性。

易错点

把 q 当成流入而不是外法向通量，或把 k/(ρcₚ) 的单位写错。

(对齐推导) 把账本套入能量守恒，拆解 ρcp 体积热容与 Fourier 定律负号，导出局部热传导方程并指出高频平滑器本质。

Step 3 · 动量守恒 + 小振幅近似

波动方程：力的差额变成加速度

微元的牛顿第二定律

张力竖直分量的差额等于质量乘加速度：

Tuxx dx=ρ dx uttT u_{xx}\,dx=\rho\,dx\,u_{tt}Tuxx​dx=ρdxutt​

于是

utt=c2uxx,c=T/ρu_{tt}=c^2u_{xx},\qquad c=\sqrt{T/\rho}utt​=c2uxx​,c=T/ρ​

方程类型 时间导数与物理机制 传播与能量特性
热传导方程 ∂T/∂t（一阶扩散，具有时间不可逆性） 抛物型：扰动瞬时传遍全域，高频抹平耗散
波动方程 ∂²u/∂t²（二阶加速度，双向波动驱动） 双曲型：沿特征线 x±ct 有限速传播，能量守恒
(微元受力) 引导看弦微元受力图，由张力竖直差额导出波动方程 utt=c²uxx，对比一阶扩散抹平与二阶往复振荡守恒。

Step 4 · 稳态极限与椭圆型平衡

泊松/拉普拉斯方程：储存项归零后的全域约束

0=∇⋅(k∇u)+Q⟺−∇⋅(k∇u)=f0=\nabla\cdot(k\nabla u)+Q\quad\Longleftrightarrow\quad-\nabla\cdot(k\nabla u)=f0=∇⋅(k∇u)+Q⟺−∇⋅(k∇u)=f

均匀无源

∇2u=0\nabla^2u=0∇2u=0

拉普拉斯方程。内部没有极值，边界决定全域。

有源项

−∇2u=f-\nabla^2u=f−∇2u=f

泊松方程。源项改变场的曲率和平均水平。

工程直觉

稳态解是输入、输出和生成在每个微元上同时平衡，而不是“没有物理”。

> 验证提醒：收敛只说明方程解出来了；F4 还要检查边界、单位、精确解和守恒。

(稳态平衡) 储存变化率归零走向全域平衡，推导 Poisson 与 Laplace 方程，指出无源调和场极值受边界约束。

Step 5 · PDE 的结构预告

同样是二阶导数，主导机制可以完全不同

对二维二阶主部 A uₓₓ+B uₓᵧ+C uᵧᵧ，看判别式 Δ=B²−4AC：

> 守恒律 → 通量本构 → PDE 类型 → 解析/数值方法

类型 判别式 代表方程 物理关键词 后续
抛物型Δ=0热传导耗散、平滑、时间方向M1.3/M2.2
双曲型Δ>0波动有限传播、特征线、能量M1.4/M2.3
椭圆型Δ<0拉普拉斯/泊松全域平衡、最大值原理M1.3/M2.1

国际单位制基底 [M=kg, L=m, T=s, Θ=K]：乘法=指数相加，除法=指数相减，开根号=指数除以2。若漏除参数或用错密度，量纲断言在 1 毫秒内拦截 F4 致命错误。

先用单位抓住不可能的方程

热扩散率满足 [α]=L²/T，波速满足 [c]=L/T。下面用 M,L,T,Θ 量纲指数自动检查，右栏分行显示计算结果和期望值。

python · 先用单位抓住不可能的方程 可编辑 · Shift+Enter 运行
def div(a,b):
    return tuple(x-y for x,y in zip(a,b))
def sqrt_dim(a):
    return tuple(x/2 for x in a)

# 量纲空间指数 [M, L, T, Θ] (kg, m, s, K)
k=(1,1,-3,-1)        # 导热系数 W/(m·K) = kg·m·s⁻³·K⁻¹
rho=(1,-3,0,0)       # 密度 kg/m³
cp=(0,2,-2,-1)       # 比热容 J/(kg·K) = m²·s⁻²·K⁻¹
tension=(1,1,-2,0)   # 弦张力 N = kg·m·s⁻²
line_rho=(1,-1,0,0)  # 线密度 kg/m (注意区分体积密度!)

# ① 核查热扩散率: α = k / (ρ·cp) -> [L²/T] (m²/s)
rho_cp = tuple(a+b for a,b in zip(rho,cp))
alpha = div(k, rho_cp)
print("[通过] 热扩散率 α 量纲 =", alpha, " 期望: [L²/T]")
assert alpha == (0,2,-1,0)

# ② 核查波速: c = √(tension / line_rho) -> [L/T] (m/s)
c = sqrt_dim(div(tension, line_rho))
print("[通过] 波速 c 量纲     =", c, " 期望: [L/T]")
assert c == (0,1,-1,0)

验证三件套 · ② 解析残差

让符号计算检查推导，而不是替你理解推导

把热核、任意行波代入相应微分算子；右栏分行显示精确残差和方程分类。残差为零只说明代入一致，物理建模仍要靠守恒与边界条件。

python · 让符号计算检查推导，而不是替你理解推导 可编辑 · Shift+Enter 运行
import sympy as sp
x,t=sp.symbols("x t", real=True)
a,c=sp.symbols("a c", positive=True)
Phi=sp.exp(-x**2/(4*a**2*t))/sp.sqrt(4*sp.pi*a**2*t)
heat_res=sp.simplify(sp.diff(Phi,t)-a**2*sp.diff(Phi,x,2))
print("[通过] 热核残差 =",heat_res)
f=sp.Function("f"); g=sp.Function("g")
u=f(x-c*t)+g(x+c*t)
wave_res=sp.simplify(sp.diff(u,t,2)-c**2*sp.diff(u,x,2))
print("[通过] 达朗贝尔残差 =",wave_res)
disc={}
for name,(A,B,C) in {"heat":(-a**2,0,0),"wave":(-c**2,0,1),"Laplace":(1,0,1)}.items():
    disc[name]=sp.simplify(B**2-4*A*C)
print("\n[分类] 热方程   Δ =",disc["heat"],"→ 抛物型")
print("[分类] 波动方程 Δ =",disc["wave"],"→ 双曲型")
print("[分类] Laplace   Δ =",disc["Laplace"],"→ 椭圆型")

验证三件套 · ③ 守恒检查

把积分账本离散成一维控制体

对稳态一维热场，−dq/dx+Q 是局部储存变化率。无源稳态时它应接近零；有源时，内部生成必须由边界净流出承担。

python · 把积分账本离散成一维控制体 可编辑 · Shift+Enter 运行
import numpy as np
import matplotlib.pyplot as plt
x=np.linspace(0,1,101); k=2.0; Q=320.0
T=20+80*x+0.5*Q/k*x*(1-x)
q=-k*np.gradient(T,x,edge_order=2); residual=-np.gradient(q,x,edge_order=2)+Q
print("max conservation residual =",f"{np.max(np.abs(residual[2:-2])):.3e}")
print("net outward flux - total source =",f"{q[-1]-q[0]-Q:.3e}")

fig, ax1 = plt.subplots(figsize=(6.2,3.2))
l1, = ax1.plot(x, T, color="#2563eb", label="T(x)")
ax1.set_xlabel("x"); ax1.set_ylabel("temperature T")
ax2 = ax1.twinx()
l2, = ax2.plot(x, residual, "--", color="crimson", label="residual")
ax2.set_ylabel("conservation residual")
ax2.set_ylim(-1.0, 1.0)
ax1.set_title("Control-volume balance: field and residual")
ax1.legend(handles=[l1, l2], loc="upper right")
plt.show()
